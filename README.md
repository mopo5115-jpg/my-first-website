# My First Website

این مخزن برای تمرین طراحی وب و یادگیری Git و GitHub ساخته شده است.

## اهداف پروژه

- تمرین HTML
- تمرین CSS
- یادگیری مدیریت نسخه با Git
- استفاده از هوش مصنوعی در برنامه‌نویسی وب

## وب‌سایت اصلی

## برنامه توسعه

در آینده نمونه‌کدها و ابزارهای کاربردی طراحی سایت به این مجموعه اضافه می‌شوند.

فایل wp-config.php و نسخه پشتیبان پایگاه داده
نباید در مخزن عمومی قرار بگیرند.
