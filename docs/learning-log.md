
# گزارش یادگیری GitHub

## روز اول
- آشنایی با مخزن (Repository)
- ویرایش فایل README.md
- ثبت اولین Commit
- مشاهده تاریخچه تغییرات (Commit History)

## هدف پروژه
ساخت نمونه‌کارهای کاربردی با HTML، CSS، JavaScript و ابزارهای هوش مصنوعی.

## برنامه ادامه مسیر
- یادگیری مدیریت فایل‌ها در GitHub
- ساخت ماشین‌حساب قیمت طراحی سایت
- انتشار پروژه به‌عنوان نمونه‌کار
- آشنایی با ساخت افزونه ساده وردپرس
